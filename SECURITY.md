# Security

## Report a security problem

Report a security problem in private, through GitHub's private vulnerability reporting:

1. Open the repo's [Security tab](https://github.com/ddl-subir-m/domino-agui/security).
2. Click **Report a vulnerability**.
3. Say what the problem is, which version has it, and how to make it happen.

Don't open a public issue, a pull request or a discussion for a security problem. A public report tells everyone about the problem
before there is a fix.

The maintainer answers in the report. A fix comes in a new release, with a security advisory on this repo.

## Supported versions

Only the latest release gets security fixes.
